常用服务（一键填好地址与模型）

绿点 = 当前网络实测可达；红点 = 当前网络连不上（用代理，或把 Base URL 换成你能访问的地址； 若服务本身是自建 / 中转，直接改地址即可）。灰点 = 未检测。

出图协议其实只有四种：ComfyUI 原生、OpenAI 的 /images/generations、 Google 的 :generateContent、以及 OpenRouter 的 chat 多模态。 任何兼容其中之一的服务都能直接接进来。

密钥默认只保存在服务端 providers.json（该文件已加入 .gitignore）， 浏览器里不留副本。勾选「在本机浏览器记住」才会写 localStorage。
